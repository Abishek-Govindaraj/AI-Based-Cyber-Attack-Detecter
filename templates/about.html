ℹ️ Model Information

🤖 AI Model

Algorithm: Random Forest Classifier

Library: Scikit-learn

Why Random Forest: High accuracy, fast training, resistant to overfitting, and works well with mixed categorical/numerical network traffic features.

📊 Dataset

Name: NSL-KDD Dataset

Training records: 125,973

Test records: 22,544

Features per record: 41 network traffic attributes

Classes: Normal, DoS, Probe, R2L, U2R

🎯 Model Performance

Overall Accuracy: 99.9%

DoS Detection: Precision 1.00, Recall 1.00

Normal Traffic Detection: Precision 1.00, Recall 1.00

Probe Detection: Precision 1.00, Recall 0.99

R2L Detection: Precision 1.00, Recall 0.97

U2R Detection: Precision 0.89, Recall 0.80 (lower due to limited training samples — only 52 examples)

⚙️ How It Works

1. Network traffic log (CSV) is uploaded through the Threat Detection page

2. Data is cleaned and encoded using the same preprocessing pipeline used during training

3. The trained Random Forest model analyzes each traffic record

4. Each record is classified as Normal or one of four attack types, with a confidence score

5. Results are stored and visualized on the Dashboard and Attack Analysis pages

🛠️ Technology Stack

Backend: Python, Flask

AI/ML: Scikit-learn (Random Forest)

Database: SQLite

Visualization: Chart.js

Frontend: HTML, CSS, JavaScript
